# Iris Flower Classification 🌸

## Project Overview

This project focuses on classifying Iris flowers into three species:
- Setosa
- Versicolor
- Virginica

The classification is performed using machine learning techniques based on the physical measurements of the flowers.

## Dataset

The Iris dataset is obtained directly from `scikit-learn` using `load_iris()`. No external dataset download is required.

The features used are:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Project Steps

1. Loaded the Iris dataset
2. Performed data inspection and exploratory data analysis
3. Checked data types and missing values
4. Generated descriptive statistics
5. Created pairplot and box plot visualizations
6. Performed feature analysis
7. Split the dataset into training and testing sets
8. Trained machine learning classification models
9. Evaluated the models using accuracy
10. Generated a confusion matrix and classification report
11. Selected the best-performing model

## Machine Learning Models

- Logistic Regression
- K-Nearest Neighbours (KNN)
- Decision Tree

## Results

The models were evaluated using:
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

Petal length and petal width were found to be highly useful features for distinguishing the Iris species.

## Conclusion

The project demonstrates how machine learning can be used to classify Iris flowers based on their physical measurements. The best-performing model was selected based on its evaluation results.
